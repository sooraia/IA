# TaxiGreen AI Fleet Management Project

This repository hosts the coursework for the IA search algorithms project focused on managing a mixed taxi fleet. The goal is to explore state representations, search strategies, simulations, and evaluation pipelines without committing to any implementation yet.

## Repository Structure

- `src/` – Python source package for the TaxiGreen codebase.
- `tests/` – Placeholder for automated tests.
- `docs/` – Space for notes and the final report.

## Next Steps

Add domain models, search strategies, simulations, and documentation as the implementation evolves.
